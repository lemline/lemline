Acknowledge the first order

Complete the SQLite setup. Keep the worker running and use a second terminal in the setup directory. Substitute java -jar lemline.jar for bin/lemline if using the JAR. Each definition below is a new version of the same workflow. Save each in turn as acknowledge-order.yaml.

Return an acknowledgement

document: dsl: '1.0.3' namespace: tutorial name: acknowledge-order version: '0.1.0' do: - acknowledge: set: message: Order received
bin/lemline definition post -f acknowledge-order.yaml bin/lemline instance start tutorial acknowledge-order 0.1.0

The CLI prints the instance ID. In the worker terminal, find that ID and the line Workflow completed with output. The worker completes the workflow with {"message":"Order received"}.

Pass data between tasks

document: dsl: '1.0.3' namespace: tutorial name: acknowledge-order version: '0.1.1' do: - prepare: set: orderId: ORD-100 - acknowledge: set: message: ${ "Order received for " + .orderId }
bin/lemline definition post -f acknowledge-order.yaml bin/lemline instance start tutorial acknowledge-order 0.1.1

The second task reads the first task's output and returns Order received for ORD-100 in the message.

Accept the customer's order ID

document: dsl: 1.0.3 namespace: tutorial name: acknowledge-order version: '0.1.2' input: schema: document: type: object required: [orderId] properties: orderId: type: string do: - acknowledge: set: message: ${ "Order received for " + .orderId + "!" }
bin/lemline definition post -f acknowledge-order.yaml bin/lemline instance start tutorial acknowledge-order 0.1.2 --input '{"orderId":"ORD-101"}'

The message now contains the ID supplied at startup.

Add conditional logic

document: dsl: 1.0.3 namespace: tutorial name: acknowledge-order version: '0.1.3' input: schema: document: type: object required: [orderId, hour] properties: orderId: type: string hour: type: integer do: - chooseGreeting: switch: - case1: when: ${ .hour < 12 } then: setMorningGreeting - case2: when: ${ .hour < 18 } then: setAfternoonGreeting - case3: then: setEveningGreeting - setMorningGreeting: set: greeting: Good morning then: createMessage - setAfternoonGreeting: set: greeting: Good afternoon then: createMessage - setEveningGreeting: set: greeting: Good evening - createMessage: set: message: '${ .greeting + ": order received for " + $workflow.input.orderId + "!" }'
bin/lemline definition post -f acknowledge-order.yaml bin/lemline instance start tutorial acknowledge-order 0.1.3 --input '{"orderId":"ORD-101","hour":10}' bin/lemline instance start tutorial acknowledge-order 0.1.3 --input '{"orderId":"ORD-102","hour":15}' bin/lemline instance start tutorial acknowledge-order 0.1.3 --input '{"orderId":"ORD-103","hour":20}'

Expect messages starting with Good morning, Good afternoon and Good evening, respectively. The switch enters one branch. The morning and afternoon tasks jump to createMessage to skip subsequent greetings. The evening task reaches it as the next task in sequence.
