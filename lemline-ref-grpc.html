gRPC Protocol Reference

This page describes the support of call: grpc tasks in Lemline.

gRPC Support Status

Lemline does not execute call: grpc tasks yet. The Open Workflow DSL defines them (see gRPC calls), and Lemline parses workflows that contain them, but no runner can run such a task: do not use it in workflows you deploy.

There are no lemline.grpc.* runner settings.

Alternative

Expose the service over HTTP (for example with a gRPC-JSON transcoding proxy) and call it with call: http:

document: dsl: '1.0.3' namespace: examples name: grpc-alternative version: '1.0.0' do: - getStock: call: http with: method: get endpoint: '${ "http://127.0.0.1:8787/products/\(.sku | @uri)" }'

Run the Examples

Every example on this page is a complete workflow. Complete the SQLite setup, save each example under the file name used below, and run the commands from the setup directory. With the JAR, substitute java -jar lemline.jar for bin/lemline.

Start the tutorial shop from the root of the Lemline source checkout:

docker compose -f examples/tutorial-services/compose.yaml up -d

Keep the setup worker running and use a second terminal in the setup directory.

bin/lemline definition post -f alternative.yaml bin/lemline instance start examples grpc-alternative --input '{"sku":"SKU-1"}'
