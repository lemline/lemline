Authentication Reference

Authentication policies are part of the Open Workflow DSL. Lemline supports basic and bearer authentication for its HTTP executor. See Supported Features for runtime support by protocol and authentication type.

Policy placement

Define a named policy under use.authentications and reference it from the endpoint with authentication.use. Declare referenced secret names under use.secrets.

document: dsl: '1.0.3' namespace: examples name: bearer-authentication version: '1.0.0' use: secrets: - apiToken authentications: partnerAuth: bearer: token: ${ $secrets.apiToken } do: - getPartnerStock: call: http with: method: get endpoint: uri: http://127.0.0.1:8787/partner/stock authentication: use: partnerAuth

Inline basic authentication

Alternatively, configure authentication.basic directly on the endpoint. The username and password fields supply the credentials.

document: dsl: '1.0.3' namespace: examples name: inline-authentication version: '1.0.0' use: secrets: - tempPassword do: - callServiceWithInlineAuth: call: http with: method: get endpoint: uri: http://127.0.0.1:8787/partner/stock # Define authentication directly here authentication: basic: username: demo password: ${ $secrets.tempPassword }

API keys and OAuth 2.0

For a service-specific API key, see How to Use API Keys for request headers and query parameters. The OAuth 2.0 guide shows the specification's client credentials configuration and describes the runtime limitation.

Use the Secrets Reference to configure secret values outside the document.

Run the Examples

Every example on this page is a complete workflow. Complete the SQLite setup, save each example under the file name used below, and run the commands from the setup directory. With the JAR, substitute java -jar lemline.jar for bin/lemline.

Start the tutorial shop from the root of the Lemline source checkout:

docker compose -f examples/tutorial-services/compose.yaml up -d

The examples read secrets from the worker's environment. Stop the setup worker with Ctrl+C, export the values, and start it again:

export apiToken='demo-token' export tempPassword='demo-password' bin/lemline listen --debug

Run the next commands from a second terminal in the setup directory.

bin/lemline definition post -f bearer-authentication.yaml bin/lemline instance start examples bearer-authentication bin/lemline definition post -f inline-authentication.yaml bin/lemline instance start examples inline-authentication
