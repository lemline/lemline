How to write jq runtime expressions

Write expressions as ${ ... }. Start with current task input ., move through fields with jq, and use pipes to break a transformation into steps.

Read and transform input

The following workflow builds an output from an array of order lines. The fallback after add handles an empty array.

To run the examples, complete the SQLite setup and keep its worker running. Run the commands from a second terminal in the setup directory. With the JAR, substitute java -jar lemline.jar for bin/lemline. Save the definition as aggregate-order-data.yaml:

document: dsl: '1.0.3' namespace: examples name: aggregate-order-data version: '1.0.0' do: - summarizeOrder: set: orderId: ${ .orderId } total: ${ [.items[] | .quantity * .price] | add // 0 } itemCount: ${ .items | length }
bin/lemline definition post -f aggregate-order-data.yaml bin/lemline instance start examples aggregate-order-data --input '{"orderId":"ORD-801","items":[{"quantity":2,"price":12.5},{"quantity":1,"price":5}]}' bin/lemline instance start examples aggregate-order-data --input '{"orderId":"ORD-802","items":[]}'

Expect {"orderId":"ORD-801","total":30,"itemCount":2}, then {"orderId":"ORD-802","total":0,"itemCount":0} for the empty order.

Keep data between tasks

Use $context for earlier values exported by a task and $workflow.input for the input supplied when the instance started.

document: dsl: '1.0.3' namespace: examples name: share-order-context version: '1.0.0' do: - identifyCustomer: set: customerId: ${ .customer.id } export: as: '${ $context + { customerId: .customerId } }' - prepareOrder: set: orderId: ${ $workflow.input.orderId } customerId: ${ $context.customerId }

Save it as share-order-context.yaml:

bin/lemline definition post -f share-order-context.yaml bin/lemline instance start examples share-order-context --input '{"orderId":"ORD-803","customer":{"id":"C-100"}}'

The second task no longer sees the customer in its input, but reads it from $context: expect {"orderId":"ORD-803","customerId":"C-100"}.

Check an expression with local data

Use the jq command-line tool on a small sample with the shape you expect the task to receive. Pass the expression inside ${ ... } to jq as its filter.

printf '%s\n' '{"items":[{"quantity":2,"price":12.5}]}' | jq '[.items[] | .quantity * .price] | add // 0'

It prints 25. Lemline evaluates expressions with a Java implementation of jq, so check functions that are new in recent jq versions in a workflow too.
