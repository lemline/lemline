OpenAPI Reference

This page describes the support of call: openapi tasks in Lemline.

OpenAPI Support Status

Lemline does not execute call: openapi tasks yet. The Open Workflow DSL defines them (see OpenAPI calls), and Lemline parses workflows that contain them, but no runner can run such a task: do not use it in workflows you deploy.

There are no lemline.openapi.* runner settings.

Alternative

Call the operation's URL directly with call: http, using the method, path, query parameters and body described in the OpenAPI document:

document: dsl: '1.0.3' namespace: examples name: openapi-alternative version: '1.0.0' do: - findGardenProducts: call: http with: method: get endpoint: http://127.0.0.1:8787/products query: category: garden output: content

Run the Examples

Every example on this page is a complete workflow. Complete the SQLite setup, save each example under the file name used below, and run the commands from the setup directory. With the JAR, substitute java -jar lemline.jar for bin/lemline.

Start the tutorial shop from the root of the Lemline source checkout:

docker compose -f examples/tutorial-services/compose.yaml up -d

Keep the setup worker running and use a second terminal in the setup directory.

bin/lemline definition post -f alternative.yaml bin/lemline instance start examples openapi-alternative
