# Semantic constraints

Check every named jump in its own task list, including switch cases. Check named retries, timeouts and reusable functions against the definitions in `use`. Verify each read against the data available at that exact step. The JVM reader accepts some constructs that still lack runtime support.

For a fork, validate each branch as a named task. For a conditional loop body, follow the next sibling after the selected action. Check that exactly the intended remote service is reached.
