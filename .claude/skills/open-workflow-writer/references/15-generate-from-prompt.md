# From a request to a workflow

Identify the trigger, supplied data, required decisions, external effects and final observable result. Keep integration details across clarifications. Resolve missing details that determine where an action goes or when it may run.

Write the smallest complete definition covering those cases. Follow one concrete input from the trigger through every side effect. Exercise it with mocked responses and check both the calls that should happen and any mutually exclusive calls that must be skipped.
