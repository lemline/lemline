# Specification and runtime support

The repository pins Open Workflow DSL 1.0.3. Use the versioned schema for structure, the JVM reader for the deployed model and the supported-features reference for execution constraints. Treat parsing and enforcing a setting as distinct checks.

In particular, check protocol executors, authentication and timeout enforcement. When a requirement exceeds the runtime’s capabilities, describe the limitation before presenting the workflow as deployable.
