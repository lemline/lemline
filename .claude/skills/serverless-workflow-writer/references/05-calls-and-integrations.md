# Service calls

For HTTP preserve the specified method, endpoint, body and response shape. Read identifiers for the next call from the original workflow input or explicitly retained context. URI-encode dynamic path segments. Verify both the request and its downstream effect with a simulated response that differs from the input.

Lemline can parse some protocol calls for which it has no executor. Consult the runtime support guide before selecting OpenAPI, AsyncAPI or gRPC.
